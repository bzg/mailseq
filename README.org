#+title: mailseq: Clojure lib for reading mailboxes

[[https://clojars.org/org.clojars.bzg/mailseq][https://img.shields.io/clojars/v/org.clojars.bzg/mailseq.svg]]

A read-only Clojure library for fetching and parsing email from IMAP
servers and Maildir directories through a unified API. Every message
is returned as a plain Clojure map.

* Installation

deps.edn:

#+begin_src clojure

#+end_src

Leiningen:

#+end_src

* Quick start

#+begin_src clojure
(require '[mailseq :as mailseq])

;; IMAP
(mailseq/with-source [src {:type :imap
                           :host "imap.example.com"
                           :user "me@example.com"
                           :password "secret"
                           :folders {"INBOX"   "INBOX"
                                     "Clojure" "Lists/clojure"}}]
  (mailseq/messages src "INBOX" {:limit 10}))

;; Maildir
(mailseq/with-source [src {:type :maildir
                           :folders {"INBOX" "/home/me/Mail"
                                     "Sent"  "/home/me/Mail/.Sent"}}]
  (mailseq/messages src "INBOX" {:since "2025-01-01" :limit 50}))
#+end_src

Both backends return the same message map structure:

#+begin_src clojure
{:id             "12345"              ;; backend-specific stable id
 :uid            12345                ;; IMAP UID (nil for Maildir)
 :message-id     "<abc@example.com>"
 :from           [{:name "Alice" :address "alice@example.com"}]
 :to             [{:name "Bob" :address "bob@example.com"}]
 :cc             []
 :bcc            nil                  ;; only populated in Maildir Sent/ with some clients
 :reply-to       [{:name "Alice" :address "alice@example.com"}]
 :subject        "Hello from mailseq"
 :date-sent      #inst "2025-02-15T10:30:00.000-00:00"
 :date-received  #inst "2025-02-15T10:30:02.000-00:00"
 :content-type   "multipart/alternative; boundary=..."
 :flags          #{:seen}
 :body           {:text "Plain text body"
                  :html "<p>HTML body</p>"
                  :attachments [{:filename "doc.pdf"
                                 :content-type "application/pdf"
                                 :size 14023
                                 :data #object[byte[] ...]}]}
 :headers        {"Subject" "Hello from mailseq" ...}}
#+end_src

* Unified API (=mailseq=)

** Opening a source

=mailseq/open= creates a source from a config map. Every source
requires a =:type= (=:imap= or =:maildir=) and a =:folders= map from
logical folder names to backend-specific locations.

#+begin_src clojure
;; IMAP: logical name -> server folder name
(def src (mailseq/open {:type :imap
                        :host "imap.example.com"
                        :user "me@example.com"
                        :password "secret"
                        :folders {"INBOX" "INBOX"
                                  "Sent"  "Sent"}}))

;; Maildir: logical name -> absolute directory path
(def src (mailseq/open {:type :maildir
                        :folders {"INBOX" "/home/me/Mail"
                                  "Sent"  "/home/me/Mail/.Sent"}}))
#+end_src

Sources implement =java.io.Closeable=. Use =mailseq/with-source= for
automatic cleanup:

#+begin_src clojure
(mailseq/with-source [src {:type :maildir
                           :folders {"INBOX" "/home/me/Mail"}}]
  (mailseq/messages src "INBOX"))
#+end_src

** Fetching messages

#+begin_src clojure
;; All messages
(mailseq/messages src "INBOX")

;; With selection options
(mailseq/messages src "INBOX" {:since  "2025-01-01"
                               :before "2025-07-01"
                               :limit  20})

;; Lightweight fetch (skip body/headers/attachments)
(mailseq/messages src "INBOX" {:limit 100
                               :body? false
                               :headers? false})
#+end_src

Selection options (identical for all backends):

| Option          | Type          | Description                                |
|-----------------+---------------+--------------------------------------------|
| =:since=        | Date / string | messages sent on/after this date            |
| =:before=       | Date / string | messages sent strictly before this date     |
| =:limit=        | int           | keep the last N most recent messages        |
| =:headers?=     | boolean       | include the full header map (default: true) |
| =:body?=        | boolean       | parse body content (default: true)          |
| =:attachments?= | boolean       | include attachment bytes (default: true)    |

Full-text search on subject, from, etc. is intentionally out of scope.
Filter the returned sequence yourself if needed.

** Fetching a single message

#+begin_src clojure
;; By backend-specific id (UID string for IMAP, filename prefix for Maildir)
(mailseq/by-id src "INBOX" "12345")  ;; => message map or nil
#+end_src

** Incremental fetching (=list-ids= / =by-ids=)

For use cases where you process messages once and want to skip
already-seen messages on subsequent runs (e.g. a batch indexer):

#+begin_src clojure
;; Step 1: get all ids (no file is read for Maildir, only UIDs for IMAP)
(def all-ids (mailseq/list-ids src "INBOX"))

;; Step 2: diff against your own persistence
(def new-ids (remove already-seen? all-ids))

;; Step 3: fetch only the new messages in one pass
(def new-msgs (mailseq/by-ids src "INBOX" (set new-ids)))
#+end_src

** Watching for new messages

The =watch-async= function works identically for IMAP IDLE and Maildir
WatchService:

#+begin_src clojure
(def t (mailseq/watch-async src "INBOX"
         (fn [msg] (println "New:" (:subject msg)))
         {:parse-opts {:attachments? false}}))

;; Later:
(.interrupt t)
#+end_src

Options are passed through to the backend: =:heartbeat-ms= for IMAP,
=:settle-ms= for Maildir. Both accept =:parse-opts= and =:on-error=.

A blocking variant =mailseq/watch= is also available.

** Incremental fetching by id range

For watermark-based incremental fetching (common in IMAP with UID
watermarks), =by-id-range= delegates to the most efficient backend
operation:

#+begin_src clojure
;; Fetch everything newer than the last known UID
(mailseq/by-id-range src "INBOX" (str (inc last-uid)) nil)

;; Fetch a specific range
(mailseq/by-id-range src "INBOX" "1000" "2000")
#+end_src

Pass =nil= as =end-id= to fetch from =start-id= to the latest message.

** Accessing the underlying IMAP connection

When you need IMAP-specific operations that the unified API does not
cover, =underlying-conn= returns the raw connection map:

#+begin_src clojure
(when-let [conn (mailseq/underlying-conn src)]
  ;; conn has :store and :session — use with mailseq.imap.* namespaces
  (mailseq.imap.folder/list-folders conn))
#+end_src

Returns =nil= for non-IMAP sources. This is a stable part of the public
API.

** Listing folders

#+begin_src clojure
(mailseq/list-folders src)  ;; => ["INBOX" "Sent"]
#+end_src

Returns only the logical folder names from your config, never a
server/filesystem scan.

* IMAP-specific API

For advanced IMAP use cases, the lower-level namespaces are available
under =mailseq.imap.*=.

** Connection (=mailseq.imap.connect=)

#+begin_src clojure
(require '[mailseq.imap.connect :as imap])

(def conn (imap/connect {:host "imap.example.com"
                         :port 993
                         :ssl true
                         :user "me@example.com"
                         :password "secret"}))

(imap/connected? conn)  ;; => true
(imap/disconnect conn)
#+end_src

OAuth2 is supported: pass =:oauth2-token= instead of =:password=.

** Fetching (=mailseq.imap.fetch=)

#+begin_src clojure
(require '[mailseq.imap.fetch :as fetch])

;; Fetch by date range
(fetch/messages conn "INBOX" {:since "2025-01-01" :limit 20})

;; Fetch by UID
(fetch/by-uid conn "INBOX" [12345 12346])

;; Fetch everything newer than a known UID
(fetch/by-uid-range conn "INBOX" 12347 jakarta.mail.UIDFolder/LASTUID)

;; Raw Jakarta Mail Message objects (IMAP only)
(fetch/messages conn "INBOX" {:limit 5 :raw? true})
#+end_src

** Folders (=mailseq.imap.folder=)

#+begin_src clojure
(require '[mailseq.imap.folder :as folder])

(folder/list-folders conn)
;; => [{:name "INBOX" :full-name "INBOX" :type :holds-messages
;;      :message-count 1042 :unread-count 3} ...]

(folder/message-count conn "INBOX")  ;; => 1042
(folder/unread-count conn "INBOX")   ;; => 3
#+end_src

** IDLE / push notifications (=mailseq.imap.idle=)

#+begin_src clojure
(require '[mailseq.imap.idle :as idle])

(def idle-thread
  (idle/idle-async conn "INBOX"
    (fn [msg]
      (println "New message:" (:subject msg)))))

;; Stop with:
(.interrupt idle-thread)
#+end_src

* Maildir backend

The Maildir backend reads =cur/= and =new/= subdirectories (never
=tmp/=). It never moves or modifies files. Each directory in the
=:folders= config must be a valid Maildir (containing =cur/= and
=new/=).

Backend-specific behavior:
- =:id= is the stable filename prefix (before the =:2,= flag suffix)
- =:uid= is always =nil=
- =:date-received= is the file's =mtime=
- =:flags= are decoded from the standard Maildir suffix (=R=, =S=, =T=, =D=, =F=)

The IMAP connection is *not* thread-safe (Jakarta Mail limitation).
Maildir is safe for concurrent reads.

** Watching for new messages (=mailseq.maildir.watch=)

#+begin_src clojure
(require '[mailseq.maildir.watch :as watch])

;; Async, returns a Thread, call .interrupt to stop
(def watcher
  (watch/watch-async "/home/me/Mail"
    (fn [msg]
      (println "New:" (:subject msg)))
    {:parse-opts {:attachments? false}}))

;; Later:
(.interrupt watcher)
#+end_src

Uses =java.nio.file.WatchService= (inotify on GNU/Linux, kqueue on
macOS). Existing messages at startup are recorded as seen - only truly
new files trigger the callback. A set of seen stable ids prevents
processing the same message twice when a MUA moves a file from =new/= to
=cur/=.

* Design principles

- *Read-only*: No sending, writing, moving, or deleting.
- *Data-oriented*: All outputs are plain Clojure maps.
- *Minimal filtering*: Only date range and limit.
- *Explicit folders*: No server/filesystem discovery.
